# SciPy numerical validation project

Run `python3 -m unittest -v test_numerical.py`. Extend the module with a noisy parameter-estimation problem. Compare at least two applicable optimizers, analytical/finite-difference gradients, starting points, scaled variables, bounds, and tolerances. Report residuals, constraint violations, convergence messages, sensitivity, function evaluations, and domain-level error. Passing requires 80/100 and independent validation of every solver result.
