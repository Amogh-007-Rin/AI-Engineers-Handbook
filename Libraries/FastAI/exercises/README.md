# fastai exercises

1. Express the project with a `DataBlock` and prove its split matches the
   intended group- or time-aware policy.
2. Write a callback that records gradient norms, then test event order and
   removal without training a large model.
3. Compare a learning-rate finder suggestion with two controlled alternatives.
4. Use interpretation tools to audit the highest-loss items and one minority
   slice, then export and reload the chosen learner in a subprocess.
