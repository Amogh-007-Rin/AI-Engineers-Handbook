# spaCy exercises

1. Add patterns that overlap and implement a documented precedence rule.
2. Write a component that assigns a registered `Doc` extension, declaring its
   required and assigned attributes and testing component-order failure.
3. Score exact and partial entity boundaries per label on held-out JSONL data.
4. Replace the blank pipeline with a pinned statistical package and measure the
   accuracy, latency, memory, and artifact-size changes.

Submit structured outputs rather than screenshots and include an offline reload
test from a fresh temporary directory.
