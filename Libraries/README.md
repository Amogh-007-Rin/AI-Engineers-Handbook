Academies teach individual tools from first contact through production practice. They complement the [concept-first curriculum](../curriculum/README.md).

Browse the complete, categorized [academy catalog](CATALOG.md). Every listed tool now has a tailored academy guide; NumPy and Pandas also contain the first authored lesson and project sets.

## Completion levels

- **Foundation:** Install, explain the mental model, and complete essential tasks.
- **Practitioner:** Build, test, debug, and evaluate an end-to-end workflow.
- **Advanced:** Optimize, extend, integrate, and operate the tool while defending tradeoffs.
- **Maintainer-ready:** Read internals, diagnose deeper failures, and contribute upstream.

Completed academies include focused lessons, recipes, troubleshooting, guided and independent projects, assessments, and a pinned CPU-first environment.
