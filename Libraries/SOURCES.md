# Primary source registry

Use this directory as the starting point for version-sensitive claims. Prefer
official documentation, release notes, source repositories, standards, and
primary papers. In project work, cite the exact page, version, and access date;
this index is not a substitute for claim-level citations.

Curated: 2026-09-04. Inclusion identifies an upstream source, not an endorsement
or a guarantee that every upstream page remains current.

## Source-use rules

- Cite the exact page or paper supporting a claim.
- Record package version and access date because APIs and defaults change.
- Distinguish documented guarantees from behavior observed in one environment.
- Check model, dataset, and asset licenses separately from library licenses.
- Keep quotations short and explain concepts in original words.
- Report broken or compromised sources through the content issue template.
