# Seaborn statistical report project

Run `python3 -m unittest -v test_distributions.py`. Extend the report with repeated measures and a subject-aware interval, then compare it with a naive row bootstrap. Include raw observations, distribution, sample size, units, stable category order, grayscale-safe encodings, alt text, semantic artifact tests, and a written warning against causal interpretation. Passing requires 80/100 across statistics, integrity, implementation, accessibility, and reproducibility.
