# Gensim exercises

1. Implement a reiterable corpus class that streams JSONL without retaining all
   documents, then prove two passes return identical vectors.
2. Sweep dictionary `no_below` and `no_above` thresholds and explain the effect
   on coverage, sparsity, memory, and validation performance.
3. Train LDA under five seeds; align topics and report stability alongside
   coherence and representative counterexamples.
4. Evaluate Word2Vec neighborhoods for task utility and one documented social
   bias risk. Compare with a lexical baseline.

Submit artifact manifests containing dictionary/model hashes and versions.
