# Statsmodels inference audit project

Run `python3 -m unittest -v test_inference.py`. Fit a model answering a prewritten estimand on open data. Publish formula, units, reference categories, missing policy, coefficient/effect intervals, residual and influence diagnostics, robust/clustered sensitivity where justified, held-out prediction behavior, and a noncausal interpretation boundary. Passing requires 80/100; post-result hypothesis changes, p-value-only reporting, or unsupported causal language require revision.
