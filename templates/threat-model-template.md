# AI system threat model

## System and assets

Define boundaries, actors, data flows, trust zones, sensitive assets, dependencies, and model capabilities.

## Threats

Consider unauthorized access, poisoning, evasion, extraction, prompt injection, data exfiltration, insecure tools, dependency compromise, denial of service, privacy loss, and harmful misuse.

## Controls and evidence

For each material threat, record likelihood, impact, prevention, detection, response, owner, residual risk, and the test proving the control.

## Approval and review

Record accepted risks, human approval boundaries, incident route, and next review date.
