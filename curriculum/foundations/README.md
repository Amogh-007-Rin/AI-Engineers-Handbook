# Software foundations learning path

This path assumes no programming background. Begin with
[orientation](00-orientation/README.md), continue through
[Python foundations](01-python-foundations/README.md), and complete the
[command-line data explorer project](project/README.md).

The full foundation outcome includes terminal navigation, files and permissions,
Git commits and branches, Python values/control flow/functions/modules, exceptions,
testing, debugging, environments, package structure, basic SQL, and clear technical
communication. Use the project as an integration gate: another learner must be
able to run it from a clean checkout and understand failures without guessing.

Progress is based on executable evidence, not familiarity. Predict behavior,
run it, explain discrepancies, add boundary tests, and record unresolved questions.
