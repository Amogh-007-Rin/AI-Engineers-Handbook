# Software foundations stage assessment

Complete the data explorer and explain it without notes. Pass at 80/100: 20
Python/control-flow reasoning, 20 decomposition and error handling, 25 automated
normal/boundary tests, 20 command-line/environment/Git reproducibility, and 15
documentation/debugging communication. Copied code the learner cannot explain,
silent malformed-input handling, or missing tests automatically fail. Remediation
requires a smaller exercise, new regression test, and clean rerun.
