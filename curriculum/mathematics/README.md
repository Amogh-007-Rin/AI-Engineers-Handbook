# Mathematics for machine learning

Mathematics here is a language for reasoning about models, not a prerequisite
wall. Begin with [linear algebra](01-linear-algebra/README.md), then complete the
[numerical reasoning project](project/README.md). Subsequent modules should cover
functions, calculus and automatic differentiation, probability, statistics,
optimization, information theory, numerical stability, and uncertainty.

For each concept, connect notation to a hand calculation, executable code, shape
or unit checks, a geometric/statistical interpretation, and a failure case. The
assessment rewards justified reasoning and verification rather than memorized
symbol manipulation.
