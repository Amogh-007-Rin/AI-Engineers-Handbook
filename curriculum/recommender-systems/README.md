# Recommender-systems learning path

This path connects retrieval, ranking, evaluation, feedback loops, exploration,
and responsible product operation. Begin with [recommender foundations](01-foundations/README.md),
then complete the [ranking evaluation project](project/README.md).

Progress requires user/time-aware splits, popularity and non-personalized
baselines, ranking metrics at product-relevant cutoffs, slice/coverage evidence,
and a plan for feedback loops, privacy, diversity, and fallback behavior.
