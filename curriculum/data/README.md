# Data foundations learning path

Reliable AI starts with reliable evidence. Study [data quality and contracts](01-data-quality/README.md),
then complete the [dataset audit project](project/README.md). The wider path
covers acquisition, consent and licensing, schemas, tabular/SQL operations,
missingness, joins, time and identity, exploratory analysis, feature pipelines,
lineage, validation, privacy, and dataset cards.

Passing work must distinguish raw, staged, and derived data; validate before
modeling; fit learned transformations on training data only; and make every row,
field, timestamp, and join assumption reviewable.
