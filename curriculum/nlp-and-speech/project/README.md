# NLP retrieval and error-analysis project

Run the transparent metric tests with `python3 -m unittest -v test_text_metrics.py`. Build a small classification, extraction, retrieval, or speech pipeline with an openly licensed dataset. Compare a lexical baseline and stronger model; publish preprocessing tests, slice metrics, error taxonomy, latency/cost evidence, dataset/model cards, and privacy/safety review. Passing requires 80/100 and no hidden test selection, unsupported factuality claim, or undocumented sensitive-data transfer.
