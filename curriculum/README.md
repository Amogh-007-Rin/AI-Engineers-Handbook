# Curriculum

The flagship curriculum is concept-first, project-centered, and competency-
gated. Tool-specific workflows live in the [Library Academies](../Libraries/README.md).

All 17 tracks have an implemented draft learning slice with a guide, metadata
lesson, executable project and tests, separated solution, and scored assessment.
“Draft available” does not imply independent review or stable publication; see
the [verification ledger](../reports/verification-status.md).

## How to progress

Each page declares prerequisites and observable outcomes. For every slice:

1. check prerequisites and placement evidence;
2. explain the core idea before using a framework;
3. implement the exercise and trigger at least one expected failure;
4. complete the independent project without opening the solution;
5. run tests and analyze what they do *not* prove;
6. score the assessment honestly and remediate weak criteria; and
7. preserve a reproducible evidence package for review.

Progress is based on demonstrated competence, not pages viewed. If you already
know a topic, complete its project and gate rather than skipping its evidence.

Begin with [orientation](foundations/00-orientation/README.md), or use the table
to enter at the first stage whose assessment you cannot yet pass.
