# Curriculum

The flagship curriculum is concept-first and competency-gated. Tool-specific workflows live in [Library Academies](../Libraries/README.md).

## Current path

| Stage | Outcome | Status |
|---|---|---|
| 0. Orientation | Establish a deliberate learning workflow | Available |
| 1. Software foundations | Write, test, debug, and package Python | In development |
| 2. Mathematics | Use the mathematical language behind ML | In development |
| 3. Data | Build correct, reproducible data workflows | In development |
| 4. Classical ML | Frame, train, evaluate, and explain ML systems | Draft vertical slice available |
| 5. Deep learning | Implement neural systems in three frameworks | Draft foundation slice available |
| 6. Computer vision | Build and evaluate robust visual systems | Draft vertical slice available |
| 7. NLP and speech | Build evaluated language and speech systems | Draft vertical slice available |
| 8. Reinforcement learning | Evaluate sequential decision systems | Draft vertical slice available |
| Domain: Time series | Forecast with temporal integrity and calibrated uncertainty | Draft vertical slice available |
| Domain: Recommender systems | Build retrieval/ranking systems with feedback-loop controls | Draft vertical slice available |
| Domain: Graph learning | Learn from relational structure without structural leakage | Draft vertical slice available |
| 9. Generative AI | Build and evaluate grounded foundation-model systems | Draft vertical slice available |
| 10. AI agents | Build bounded, evaluated tool-using systems | Draft vertical slice available |
| 11. Production AI | Deploy, observe, and recover AI systems | Draft vertical slice available |
| 12. Responsible AI | Govern impact, privacy, security, and fairness | Draft vertical slice available |
| 13. Research | Reproduce and extend evidence responsibly | Draft vertical slice available |
| 14. Career and capstone | Defend a production-grade AI system | Draft vertical slice available |

Each page declares prerequisites and observable outcomes. Complete its exercises and criteria before advancing. Begin with [orientation](foundations/00-orientation/README.md).

Current stage entry points: [classical machine learning](machine-learning/README.md), [deep learning](deep-learning/README.md), [computer vision](computer-vision/README.md), [NLP and speech](nlp-and-speech/README.md), [time series](time-series/README.md), [recommender systems](recommender-systems/README.md), [graph learning](graph-learning/README.md), [reinforcement learning](reinforcement-learning/README.md), [Generative AI](generative-ai/README.md), and [agents](agents/README.md).
