# Portfolio and capstone readiness project

Choose two contrasting projects and build evidence manifests for each: problem,
stakeholder, baseline, data/model provenance, tests, evaluation, decisions,
limitations, security/responsibility, operations, and reproducible command. The
starter validates the manifest; run `python3 -m unittest -v`.

Then write a capstone proposal containing a decision and success criteria,
architecture, dataset/model cards, offline/online evaluation, threat model,
compute/cost budget, rollout/monitoring/rollback, demo plan, and retrospective
questions. Deliver a ten-minute demo and answer one failure-analysis challenge.
