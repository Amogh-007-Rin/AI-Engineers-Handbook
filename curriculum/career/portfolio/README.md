# AI engineering portfolio review

Submit four artifacts: classical ML/data, deep or domain AI, GenAI/agents, and production/research. Each must include a reproducible repository, concise case study, tests, evaluation, failed approach, risk analysis, and contribution statement.

Reviewers score problem framing, foundations, experimental reasoning, engineering, operations, responsible practice, and communication. A pass requires 80/100 overall with no category below 70. During a 45-minute defense, reproduce one result, diagnose one seeded failure, explain one tradeoff, and identify what evidence would change a key decision.
