# Responsible AI integrated review

Audit an earlier project using dataset/model cards and the threat-model template. Produce stakeholder map, harm scenarios, slice evaluation with uncertainty, privacy lifecycle, accessibility review, misuse cases, red-team tests, controls, residual-risk register, human-oversight design, incident route, and retirement triggers. Passing requires 80/100 across evidence, affected-party analysis, controls, governance, and communication. A principle without an owner and verification method does not count as a control.
